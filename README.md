# tidyOrg — downloads

Signed installers of **tidyOrg**, the local-first Salesforce toolkit for admins, developers and consultants by 3D&TECH LAB d.o.o.

**Product page:** https://3dtechlab.hr/tidyorg/

## Download

Open the [latest release](https://github.com/CrOsman/tidyorg-releases/releases/latest) and pick your file:

| File | For |
| --- | --- |
| `tidyOrg-Setup-<version>.exe` | Windows 10/11 (x64): installs per user, no admin rights needed |
| `tidyOrg-<version>-portable.exe` | Windows, where installing programs is not allowed: starts without installing |
| `tidyOrg-<version>-mac.dmg` | macOS (Apple silicon and Intel) |

The Windows files are signed by 3D&TECH LAB d.o.o.; the macOS app is signed with a Developer ID and notarized by Apple.
